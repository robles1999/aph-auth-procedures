Required Preparation Steps

1

Review referral communications history. Continue with verification if needed.

2

Make sure we have a valid RX (Prescription/Referral) on file, print and/or save to computer as it might be needed to request auth.

If a valid RX is not on file, follow established process to request an updated RX from the provider.

3

Ensure coverage eligibility by way of Registration (RTE), Passport, or Insurance Portal.

If the RTE is used, it is a good idea to also review the Response History to check for any alerts or issues with the insurance that may require follow-up.

4

Submit Auth through payer portal or paper form.

General

Authorization Scenarios

If authorization is not required:

  • Status: Authorized
  • Auth Reason: No Payer Auth Required

If authorized:

  • Status: Authorized
  • Auth Reason: Received payer authorization

If authorization is pending:

  • Status: Pending review
  • Auth Reason: Authorization initiated
2

Communications

If no Auth Required:

  • Add a Rehab Note: SmartPhrase 👉 REHABNOTE
    PER ONLINE RESPONSE FROM {insurance}. NO AUTH REQUIRED.
  • Copy the Portal result and paste it into the Rehab Note.

If Authorized:

  • Add a Rehab Auth Summary Approval note: SmartPhrase 👉 REHABAUTHAPPRVL
  • Fill out the REHABAUTHAPPRVL note with the authorization response.

If Auth is PENDING or Manual Auth was submitted:

  • Add a Rehab Auth Pending note: SmartPhrase 👉 REHABAUTHPEND
  • Referral Icon (X) will remain Red.
  • No further changes needed until AUTH is approved.
